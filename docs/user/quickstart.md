Getting started with PriEco is easy

## Try PriEco

First lets give PriEco a try at [prieco.net](https://prieco.net/)

Make sure PriEco correctly detects your desired language and location in settings menu and you can toggle other settings too

Do a few searches and see if you like it

- If not we would like to know why. You could email us at [support@prieco.net](mailto:support@prieco.net) or join our chat platforms at [prieco.net](https://prieco.net/) footer. Your message can be totally unformal, the core reason is the only important part for us

If you do like PriEco, let's set it up as your default web search engine

## Default search engine

### Google Chrome (Chromium browsers)

To this group of browsers belongs Google Chrome, Microsoft Edge, Brave browser, Opera, Vivaldi and many more

#### Browser extension

The easiest way would be to add our [extension](https://chromewebstore.google.com/detail/prieco/phinbldohjiiggbnhamnejgniccmgome) to your browser. It sets PriEco as a new tab page and a default web search engine automatically for you

Your browser may ask you if you approve with the changes, approve them

#### Manual set up

If you wish to set up PriEco as a default web search engine manually here is how to do it:

- Go to settings → Search engine → Manage search engines and site search
- Site search (Click Add)

Fill in

- Name: PriEco
- Shortcut: prieco.net
- URL with %s in place of query: https://prieco.net/search?t=all&q=%s

### Firefox (Firefox based browsers)

To this goup belongs Firefox, LibreWolf, Mullvad Browser, Tor browser and more

#### Browser extension

The easiest way would be to add our [extension](https://addons.mozilla.org/en-US/firefox/addon/prieco/) to your browser. It sets PriEco as a new tab page and a default web search engine automatically for you

Your browser may ask you if you approve with the changes, approve them

#### Manual set up

If you wish to set up PriEco as a default web search engine manually here is how to do it:

- Open [prieco.net](https://prieco.net/)
- Right click on the omnibox, it is the URL bar at the top of the browser
- Click on "Add: PriEco"
- Navigate to settings → Search
- Select PriEco in "Default search engine"
